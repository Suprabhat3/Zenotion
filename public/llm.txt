# Zenotion

> Markdown-first note management for developers. Organize specs, RFCs, and daily notes with folders, tags, autosave, public sharing, and bring-your-own-key AI assistance — free forever.

Zenotion is a Notion-style notes web app built for developers who live in markdown. It is a calm workspace for meeting notes, API specs, RFCs, runbooks, daily logs, and side-project docs — without a block editor learning curve.

Your markdown workspace for specs, RFCs, and daily notes — organized, autosaved, and always free.

## Always free — a gift from one developer to another

Built because every developer deserves a calm place for notes — without another subscription eating into side-project budgets.

### The platform: 100% free, forever

- Unlimited notes, folders, and tags
- Markdown editor with live preview

- Public share links

AI is optional — use notes without AI anytime.

## Core features

### Markdown + live preview

Split-pane editor with sanitized GitHub Flavored Markdown (GFM) preview. Write the way you document code — README-style, predictable, and portable.

### Folders & tags

Group specs, sprints, and snippets. Tag by team, topic, or project and find anything in seconds. Mirror how you think about repos without friction.

### Autosave & version history

Every edit persists in the background. Roll back to earlier versions when you need to. Stop worrying about losing a draft mid-thought.

### AI command palette

Summarize, rewrite, outline, extract tasks, and more — one shortcut, bounded to your note. Works on full notes or selected text for inline actions.

### Public share links

Publish RFCs, runbooks, or docs with a URL when you are ready to ship. Private by default; public sharing is always an explicit opt-in.

### Calm dev-friendly UI

Light and dark themes, claymorphism-inspired surfaces, version history, keyboard-friendly flows, and a focused interface that stays out of your way.

### Authentication

Email/password sign-in and optional Google OAuth via Better Auth. Your notes are scoped to your account unless you choose to share them.

## Typical workflow

1. **Capture** — Drop meeting notes, API specs, or ideas in markdown. No block editor learning curve.
2. **Organize** — Sort into folders and tag by team, sprint, or topic. Find anything in seconds.
3. **Ship** — Keep notes private or share publicly. Your workflow, your rules.

## AI command palette actions

Available inside the note editor for authenticated users with a configured API key:

- **summarize** — Condense long notes into key points
- **rewrite** — Clearer wording, same meaning
- **continue** — Pick up where you left off
- **fix-grammar** — Polish spelling and punctuation
- **change-tone** — Adjust voice for your audience
- **extract-tasks** — Turn prose into actionable checklists
- **generate-title** — Name a note from its content
- **create-outline** — Structure ideas before you expand
- **simplify** — Make dense text easier to read
- **translate** — Reach readers in another language
- **flashcards** — Study material from your notes
- **clean-markdown** — Fix messy pasted text into proper markdown

Inline AI actions (on selected text): rewrite, simplify, fix-grammar, change-tone, translate.

## Privacy & security

- Notes are private by default and tied to your authenticated account
- Public sharing requires an explicit toggle per note
- AI API keys are stored encrypted in the browser — never sent to or stored on Zenotion servers
- Markdown preview output is sanitized for safe rendering
- AI requests are routed through a server endpoint; clients do not call providers directly

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Prisma, PostgreSQL, Better Auth, OpenAI SDK (multi-provider), Zod validation.

Rendering: SSR for authenticated dashboard and note editor; ISR for templates gallery; dynamic SSR for public shared notes.

## Protected app areas

These routes require sign-in and are not intended for indexing or automated crawling:

- /dashboard — note list and workspace home
- /notes/[id] — private markdown editor
- /login — sign in
- /signup — create account

## API

HTTP route handlers under /api/ are for authenticated app use (notes CRUD, AI completion, auth) and are not public documentation endpoints.
